# Systemanforderungen

Typemill ist eine leichte Software mit minimalen Anforderungen. Alles, was Sie benötigen, ist:

* **PHP 8.2 - 8.5**
* **Ein Webserver** (Apache bevorzugt; NGINX und IIS sind ebenfalls möglich)
* **FTP** oder eine andere Methode zum Hochladen von Dateien auf Ihren Server
* **Keine Datenbank** erforderlich; Typemill speichert alles in Dateien.

Fast jedes Hosting-Paket stellt einen Webserver mit PHP zur Verfügung. Wenn Sie bereits Web-Software wie WordPress gehostet haben, können Sie Typemill ohne Probleme ausführen.

## Unterstützte Browser

Typemill unterstützt die folgenden Browser, geordnet nach Testgründlichkeit:

* **Firefox** (intensiv getestet)
* **Chrome** (getestet)
* **Edge** (grundlegende Tests)
* **Safari** (grundlegende Tests)

Wenn Sie Probleme in anderen Umgebungen feststellen, melden Sie diese bitte, indem Sie ein neues Issue auf [GitHub](https://github.com/typemill/typemill) erstellen.
