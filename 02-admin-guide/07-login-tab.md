#  Login Tab

In the login tab, you can customize the login and authentication pages with text colors, background colors, layout, and text. You can also determine the redirect targets for different user groups after they log in. Please also read the article about [user roles](/admin-guide/users) and [page restrictions](/author-guide/page-restrictions).

![Screenshot of the Login tab](media/live/login-tab.webp){.center loading="lazy" width="820" height="548"}

| Option | Description |
|:---|:---|
| Background Color (form) | Define the background color of the page area with the input forms. |
| Text color (form) | Define the text color of the page area with the input forms. |
| Background Color (info) | Define the background color of the page area with the info text. |
| Text color (info) | Define the text color of the page area with the info text. |
| Content for the login form | Add text for the login page. If empty, the login page shows the default text. If filled, this content is shown only on the login page. Other pages, like password recovery, always show their original content. |
| Stacked layout | If activated, the info text appears at the top and the form below on all screen sizes. |
| Redirect after login for users with admin rights | Redirect users with admin rights to a specified page after login. The default is the content editor. Options include system page, editor page, account page, and homepage. |
| Redirect after login for users with edit rights | Redirect users with edit rights to a specified page after login. The default is the content editor. Options include editor page, account page, and homepage. |
| Redirect after login for users without edit rights | Redirect users without edit rights to a specified page after login. The default is the account page. Options include account page and homepage. |
