# Live Migration

One of the biggest advantages of a flat-file CMS like Typemill is the simple migration process. You can develop your website on localhost and move it to a live server when it is ready. You can also download a live website back to localhost or move it to another server at any time.

After moving the website to a new domain, clear the cache and regenerate the navigation with the new base URL. Open the Kixote interface, run `clear cache`, then run `clear navigation`. After that, the migration is complete.
